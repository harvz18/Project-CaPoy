# UX evaluation and severity

## Evidence

Record the route/state, user goal, observed behavior, expected behavior, affected roles/platforms, and how the finding was verified. Screenshots and code inspection support findings but do not replace user testing.

## Severity

- `0` — not a usability problem or insufficient evidence.
- `1` — cosmetic/minor friction with an obvious workaround.
- `2` — meaningful friction, confusion, or accessibility risk that slows completion.
- `3` — major problem that frequently blocks or misleads a primary task.
- `4` — critical safety, privacy, data-loss, authorization, or universal task blocker.

Fix higher severity first. Prefer shared, reversible solutions. For each fix define an observable acceptance check and report tested, not tested, or blocked.
