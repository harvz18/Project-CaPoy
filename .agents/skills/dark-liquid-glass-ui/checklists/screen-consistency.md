# Screen Consistency Checklist

Use this checklist for every inventory item.

- [ ] Inherits the dark ocean background without abrupt white/black gaps.
- [ ] Uses centralized semantic tokens and shared material presets.
- [ ] Has clear hierarchy; highlighted glass is reserved for a focal element.
- [ ] Primary/secondary/muted text remains readable over the brightest background area.
- [ ] Buttons, inputs, cards, badges, and icons match shared variants.
- [ ] Active navigation is correct for the current route and not communicated by color alone.
- [ ] Safe areas, scrolling, keyboard, long text, and bottom navigation clearance work.
- [ ] Loading, empty, error, offline, permission, success, disabled, and pending states that can occur are styled.
- [ ] Focus, pressed, selected, loading, invalid, and disabled interaction states are present where relevant.
- [ ] Modals/overlays have readable elevated material and correct dismiss/focus behavior.
- [ ] Mobile, tablet, and desktop composition is appropriate where supported.
- [ ] Reduced motion/transparency and high-contrast behavior are acceptable.
- [ ] No route, API call, validation rule, data model, or business interaction changed unintentionally.
- [ ] No old pastel/light surface, default control, random gradient, or one-off glass value remains.
- [ ] Verification evidence and any unresolved issue are recorded.
